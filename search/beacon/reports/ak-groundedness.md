# Claim check without an LLM: scored once on unseen passages

Code: `src/beacon/groundedness.py`. Plan and thresholds: `evals/experiment_grounded.py` and
`evals/frozen-grounded.json`. Numbers: [`ak-groundedness.json`](ak-groundedness.json).

The check looks for evidence that a cited passage does not say what a claim says: numbers and law
citations missing from the source, too few shared terms, a negation that differs from the closest
sentence, and low embedding similarity. It uses no LLM and no network.

A separate AI agent wrote the claims without seeing the checker: four for each of 80 real
Algoritmekader passages. Two more failure types were generated by script. Passages were split by
hash. Thresholds were chosen on the dev half to catch the most false claims with at most 15% false
alarms, then the 45 test passages were scored once.

| Claim type | n | Flagged |
| --- | --- | --- |
| Cites the wrong passage | 45 | **100%** |
| Changed number | 9 | 89% |
| Hallucinated detail | 45 | 87% |
| Subtly false (reversed duty, wrong actor, changed scope) | 45 | **58%** |
| Faithful, close to the source | 45 | 4% false alarms |
| Faithful, reworded | 45 | 20% false alarms |

Over the two written false types it caught 72%, with 12% false alarms over the two faithful types.

## What this says

- **It catches sloppy failures, not clever ones.** A wrong source or an invented detail nearly always
  shows up. Four in ten subtle errors got through, and those are the ones that do harm.
- **A clean result proves nothing.** It only means no problem was found, and the tools say so.
- **Reworded but correct text gets flagged one time in five.** Show a flag as "check this", never
  as "wrong".
- **The can-or-must check did not earn its place.** Tuning turned it off, so `kan` turned into
  `moet` is only caught by the other signals.

## Limits

These claims were written by an AI asked to fool a checker it could not see. Claims from a real LLM
answering real questions may behave differently, and no real LLM has been run here. All text comes
from one corpus, and the wrong-source case is an easy version where the other passage is random.
