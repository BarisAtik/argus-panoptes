# 📓 Arena notebook

Notes from sanctioned competitions. This folder holds classes of weakness and lessons,
never working submissions.

## Before committing anything

1. Is the competition's disclosure window over? Gray Swan's IPI Black rules forbid sharing breaks
   until 30 days after the challenge ends, on pain of disqualification. General discussion of
   technique is allowed.
2. Would this text work if pasted into the target? Then it does not go in a public repo.
3. Does it name a model the rules say not to identify?

## Rules worth remembering

- Every submission is entered by hand. Scripts, bots, API calls and bulk tools are disqualifying on
  Gray Swan. Nothing in this repo connects to any arena, and it should stay that way.
- One account per person. Keep country and contact details current.
- AI tools may help draft attacks, but some providers restrict this and may act on accounts.
- Never try to leave the sandbox. That is a permanent ban.
